# Open Bio Seminars feed

Calendar feed of open biology seminars marked **Interested** in Open Seminar Finder.
Rebuilt every Monday by a scheduled Claude task.

Subscribe in Google Calendar: Other calendars → + → From URL, and paste:

https://raw.githubusercontent.com/GavinLu42/open-bio-seminars-feed/main/seminars.ics

`build_ics.py` turns the seminar records into `seminars.ics`.
